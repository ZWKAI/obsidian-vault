### 提示词
```
我要在此服务器上部署一个新项目（财务工具平台）。项目信息都要放在@finTools 下面，其中code里放代码相关数据，data文件夹放数据库和挂载文件。项目源代码在我本地电脑，路径：/Users/wenkai/it/cursor/fin-tools。给我一个迁移计划，要求：
1.不能影响现有服务器上面的现有项目
2.后续此服务器还要部署其他项目，要考虑扩展性
3.方便手动部署、停止、重启
4.方便备份、升级
```
### 部署
#### 1. 同步源码：

```bash
rsync -av --delete \
--exclude '.git' --exclude '.env' \
--exclude 'node_modules' --exclude 'backend/.venv' \
--exclude 'frontend/dist' --exclude 'data' \
--exclude '__pycache__' --exclude '.pytest_cache' \
/Users/wenkai/it/cursor/fin-tools/ \
root@22.50.100.13:/data/finTools/code/app/
```
**todo**:后续可改为git
#### 2. 构建
```bash
/data/finTools/bin/build

## 构建镜像历史
k3s ctr images ls -q | grep -v '^sha256:' | grep -v '@sha256:'| grep 'fintools'

## 删除镜像
k3s ctr images rm docker.io/library/fintools-app:<旧标签>
```

#### 3. 部署

```bash
/data/finTools/bin/up
```
