### 启动
```
exec ./deploy/docker-up.sh test

```
### 常用命令
```
# 1. Worker 是否在跑

docker compose ps

# 2. Worker 日志（看有没有 startup_failed / poll_failed）

docker compose logs worker --tail=100

# 3. 确认 API 与 Worker 连的是同一个库

docker compose exec api printenv LEXIREVIEW_DATABASE_URL

docker compose exec worker printenv LEXIREVIEW_DATABASE_URL
```
