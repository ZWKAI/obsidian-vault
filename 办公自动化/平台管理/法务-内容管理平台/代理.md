### 重启代理
sudo systemctl restart mihomo

**关闭** 
sudo systemctl stop mihomo

	**查看状态：**
	systemctl is-active mihomo

**禁用开机自启动：**
```
sudo systemctl disable mihomo
```
	查看状态：
	systemctl is-enabled mihomo
