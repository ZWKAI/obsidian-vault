
### 摊余成本模块 V0.1 新增确认项

**摊余成本利息(元)** 来源于：

```text
综合核算分析表
AY列
```

因此，摊余成本模块 V0.1 的最终取数逻辑更新如下：

---

## 数据来源

业务数据来源：

```text
综合核算分析表
```

客商编码来源：

```text
客商编码.xlsx
```

---

## 筛选条件

程序运行：

```text
请输入月份：
```

筛选：

```text
放款主体
=
北京融汇智达商业保理有限公司
```

（按照我们目前确认的规则，不再增加其它筛选条件。）

---

## 输出 Sheet

### Sheet1

```text
摊余筛选明细-XX月
```

保留筛选后的全部字段。

---

### Sheet2

```text
摊余数透-XX月
```

汇总维度：

```text
业务产品
+
融资企业名称
```

汇总字段：

```text
AY列
=
摊余成本利息(元)
```

即：

```text
按业务产品
按融资企业名称
汇总AY列金额
```

---

### Sheet3

```text
XX月#摊余收入
```

字段：

| 列 | 内容              |
| - | --------------- |
| A | 业务产品            |
| B | 融资企业名称          |
| C | XX月摊余收入（AY汇总金额） |
| D | 客商编码（VLOOKUP）   |

---

## 客商编码

依据：

```text
融资企业名称
```

查：

```text
客商编码.xlsx
```

填入：

```text
客户辅助核算
```

---

## 凭证

摘要：

```text
确认6月摊余收入-XX公司-XX产品
```

其中月份动态。

科目：

```text
1133680101
其他应收款_应收利息_正常贷款利息_信用贷款利息
```

借方：

```text
AY汇总金额
```

项目编码：

```text
9999
```
