## 一、文件解析失败
1.### 查失败原因
```
docker exec WeKnora-postgres psql -U weknora -d weknora -c "
select id, title, file_type, parse_status, error_message, created_at, updated_at
from knowledges
where title ilike '%分贝通报销流程%'
order by created_at desc
limit 5;
"
```
2.### 查是否生成了分块
```
docker exec WeKnora-postgres psql -U weknora -d weknora -c "
select count(*) as chunks
from chunks
where knowledge_id='821e9a2e-8b5a-4ae7-a93d-076f242bb657'
and deleted_at is null;
"
```
