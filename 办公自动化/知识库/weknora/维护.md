### 镜像更新
```
cd /root/weknora
docker compose pull
docker compose up -d
```
### 查看日志
常用日志查看命令如下，当前运行目录是：

```bash
cd /root/weknora-v0.6-custom
```

## 查看各服务日志

### 后端 app 日志

```bash
docker logs -f WeKnora-app
```

最近 30 分钟：

```bash
docker logs WeKnora-app --since 30m
```

只看错误：

```bash
docker logs WeKnora-app --since 30m 2>&1 | grep -iE "error|failed|panic|CUDA|MinerU|docreader"
```

### 文档解析 docreader 日志

```bash
docker logs -f WeKnora-docreader
```

最近 30 分钟错误：

```bash
docker logs WeKnora-docreader --since 30m 2>&1 | grep -iE "error|failed|exception|traceback|parse|pdf"
```

### 前端 nginx 日志

```bash
docker logs -f WeKnora-frontend
```

### 数据库日志

```bash
docker logs -f WeKnora-postgres
```

## 查某个文档解析失败原因

比如查「分贝通」：

```bash
docker logs WeKnora-app --since 2h 2>&1 | grep -iE "分贝|MinerU|CUDA|failed|document read"
```

查「携程」：

```bash
docker logs WeKnora-app --since 2h 2>&1 | grep -iE "携程|MinerU|CUDA|failed|document read"
```

## 查数据库里的失败记录

```bash
docker exec WeKnora-postgres psql -U weknora -d weknora -c "
SELECT title, parse_status, enable_status, updated_at, error_message
FROM knowledges
WHERE parse_status = 'failed'
ORDER BY updated_at DESC
LIMIT 10;
"
```

## 看当前容器状态

```bash
docker ps --filter "name=WeKnora"
```

## 当前这次错误的重点日志关键词

你这次重建失败，可以搜：

```bash
docker logs WeKnora-app --since 2h 2>&1 | grep -iE "MinerU|CUDA out of memory|821e9a2e|分贝"
```

结论里如果看到 `CUDA out of memory`，就是外部 MinerU/GPU 显存不足。
