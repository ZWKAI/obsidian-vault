## 执行步骤
根据数据内容查询分组logits,然后根据softmax转换为概率值，然后根据一下配置选择
logits -> temperature -> softmax   -> Top_p  -> Top_k   -> num_beam = sample(样本值) 
## 算法及参数
1. **贪心算法**
 每次都取概率大的token
 2. **num_beam**2
 概率乘积
num_beam=2 : 当前组token概率 * 下一组token概率 ，取最大
3. Top_k
Top_k=2:只取前2个概率最高的token
4. Top_p
适用于概率平缓的情况
Top_p = 0.8 ：token概率从大到小累计值超过0.8
5. Temperature(温度)
参数调节，一般是0.5 到2之间，计算公式为softmax/temperature
temperature = 0.5 : 使概率比较大的token变的更大，使概率比较小的token变的更小 （增加确定性）
temperature = 2 ：使概率比较大的token变的小一些，使概率比较小的token变的比较大一些（增加随机性）
