Superpowers 是一套自动介入开发流程的“工作方法库”，帮助 Agent 更可靠地完成软件工程任务。

主要能力：

- `/brainstorming`：开发前澄清需求、设计方案
- `/writing-plans`：把需求拆成可执行计划
- `/test-driven-development`：按 TDD 流程先写测试再实现
- `/systematic-debugging`：系统定位 Bug 根因
- `/verification-before-completion`：完成前运行验证，避免未经证实地声称成功
- `/requesting-code-review`、`/receiving-code-review`：发起和处理代码审查
- `/dispatching-parallel-agents`：并行处理互不依赖的任务
- `/subagent-driven-development`：使用子 Agent 分工实施计划
- `/using-git-worktrees`：在隔离工作区开发
- `/executing-plans`：按已有计划分阶段执行
- `/finishing-a-development-branch`：完成后选择合并、创建 PR 或清理分支
- `/writing-skills`：创建和验证新技能

使用方式：

1. 直接输入命令，例如 `/systematic-debugging`
2. 直接描述任务，例如“修复这个测试失败”，Agent 会自动选择对应技能
3. 插件规则和 `sessionStart` Hook 会自动生效，无需手动运行

典型流程：

`需求 → brainstorming → writing-plans → TDD → 实现 → code review → verification → 完成分支`

核心特点是：先选择正确流程，再执行操作；先拿到验证证据，再宣布完成。
