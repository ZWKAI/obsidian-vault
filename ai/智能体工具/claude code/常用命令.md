### 启动后有三种工作模式：
通过 `Shift+Tab` 切换[](https://cloud.tencent.cn/developer/article/2573107?from=15425&frompage=seopage)

| 模式                   | 快捷键          | 用途               |
| -------------------- | ------------ | ---------------- |
| **Interactive mode** | 默认           | 每步需用户确认，适合复杂任务   |
| **Auto-accept mode** | Shift+Tab    | 自动执行，适合简单明确的任务   |
| **Plan mode**        | Shift+Tab 两次 | 只生成计划不写代码，适合前期规划 |

**推荐工作流**[](https://cloud.tencent.cn/developer/article/2573107?from=15425&frompage=seopage)：

1. 进入 **Plan mode**，粘贴完整需求
    
2. 让 Claude 先复述理解、产出技术方案
    
3. 多轮讨论确认方案后，再让它写代码

### 启动与会话[](https://cloud.tencent.cn/developer/article/2661746?policyId=20240000&traceId=&frompage=homepage)[](https://developer.aliyun.com/article/1736024)

|命令|说明|
|---|---|
|`claude`|启动交互模式|
|`claude -c`|在当前目录继续最近对话|
|`claude "任务描述"`|一次性运行任务|
|`claude -p "查询"`|一次性查询（不执行修改）|

### 内置斜杠命令[](https://cloud.tencent.cn/developer/article/2573107?from=15425&frompage=seopage)[](https://developer.aliyun.com/article/1736024)

| 命令         | 说明                         |
| ---------- | -------------------------- |
| `/init`    | 扫描项目生成 `CLAUDE.md` 作为项目知识库 |
| `/clear`   | 清空对话上下文（对话过长时使用）           |
| `/compact` | 压缩上下文，节省 Token             |
| `/model`   | 切换模型                       |
| `/status`  | 查看当前配置与模型                  |
| `/cost`    | 查看 Token 消耗                |
| `/diff`    | 查看文件修改记录                   |
| `/exit`    | 退出                         |
