想要用好全新的 **Antigravity CLI (`agy`)**，除了日常的敲代码和提问外，掌握它底层的“多智能体编排（Agentic）”和快捷指令能让你的终端效率翻倍。

这里为你整理了进阶使用的核心技巧与高频快捷键：

### 一、 核心斜杠指令（Slash Commands）

在 `agy` 的互动式终端 UI（TUI）中，输入 `/` 即可触发命令补全。以下是最常用的几个指令：

- **`/grill-me`（强烈推荐）：** 在让 AI 执行模糊或复杂的任务（如“重构这个模块”）前使用。它会主动向你抛出几个关键的澄清问题，确认后再动手，**能极大减少因为理解偏差而浪费 AI Pro 额度**。
    
- **`/goal`：** 开启完全自主任务模式。当你对当前项目的 Plan（实施计划）非常满意时，用它让 AI 独立运行到最终完成。
    
- **`/btw <问题>`：** 在后台问一个不相干的问题。比如主智能体正在帮你写复杂的后端逻辑，你可以用 `/btw 这个算法的复杂度是多少？` 来查资料，不会污染和中断当前的上下文。
    
- **`/rewind`（或 `/undo`）：** 撤销魔术。如果 AI 刚刚执行的一步搞砸了，或者你想换个思路，可以用它将对话历史和代码状态**回滚到前一步**。
    
- **`/fork`：** 分叉会话。当前思路想保留，但又想尝试另一种激进的代码架构？用 `/fork` 复制当前状态到新线程，双管齐下。
    
- **`/mcp`：** 管理模型上下文协议（Model Context Protocol）。可以用它直接连接外部的 MCP 服务器（如本地数据库、特定 API 文档等）。
    

### 二、 高效交互快捷键

熟练使用快捷键可以让你免于在鼠标和键盘间切换：

|**快捷键**|**动作行为**|
|---|---|
|**`Shift + Enter`** 或 **`Ctrl + J`**|在输入框中**插入换行符**（直接按 `Enter` 是提交）。|
|**`Ctrl + O`**|**展开/折叠 AI 的思考轨迹（Trajectory）**。当你想看它调用工具的底层细节时非常有用。|
|**`Ctrl + R`**|**打开 Artifact（交付物）审查面板**。在侧边栏直接对比和查看 AI 修改的文件 Diff。|
|**`@` （在输入框键入）**|**触发路径/文件自动补全**。快速把本地文件挂载到 prompt 里。|
|**`y` / `n`**|当 AI 请求运行某条终端命令或写文件时，快速批准（Yes）或拒绝（No）。|

### 三、 进阶技巧与“黑客模式”

#### 1. 节省 AI Pro 额度的“精细化授权”

默认情况下，AI 每次执行终端命令或修改文件都会弹窗让你确认（`request-review`）。如果嫌烦，**千万别盲目开启全自动**。

你可以在终端输入 `/permissions` 或直接修改 `~/.gemini/antigravity-cli/settings.json`，配置命令白名单：

JSON

```
{
  "permissions": {
    "allow": [
      "command(git)",
      "command(npm test)"
    ],
    "deny": [
      "command(rm -rf)"
    ]
  }
}
```

_这样，Git 提交和运行测试等无害操作会自动执行，而危险操作依然会被拦截。_

#### 2. 临时测试的“沙箱保护”

如果你让 `agy` 帮你写一段复杂的跑批脚本，但你不太确定它会不会污染本地环境，可以在启动时加上沙箱参数：

Bash

```
agy --sandbox
```

它会在 macOS 的 `sandbox-exec` 或 Linux 的 `nsjail` 中隔离运行 AI 生成的命令，完全不怕搞崩系统。

#### 3. 终极自动化：YOLO 模式（慎用！）

如果你在纯粹的测试目录或 Docker 容器里，想要让 AI 彻底放开手脚自动解决一个复杂问题（比如连续修复 10 个报错的自动化测试），可以在启动时输入：

Bash

```
agy --dangerously-skip-permissions
```

AI 将完全跳过所有确认提示，一路狂飙直到达成目标。**切记：请仅在完全隔离的安全环境中使用此模式。**

#### 4. 终端与桌面端无缝同步

当你用 `agy` 处理任务中途发现需要复杂的可视化图表或大面积的代码比对时，可以直接关闭 TUI。`agy` 会在退出时在终端打印出一行特定的**恢复命令**。你可以直接把当前会话导入到桌面端 **Antigravity 2.0** 中，所有的历史 Transcript 和临时 Scratchpad（暂存区）都会完美同步。
