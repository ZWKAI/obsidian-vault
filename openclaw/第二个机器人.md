	3. Copy auth profiles from "main"?`
		建议选 `Yes`。
		原因：
		- 新 agent 会继承 `main` 里已经配好的模型/API 认证。
		- 这样新 agent 创建后马上就能用，不用再重新填一遍模型密钥。
		- 这不会自动共享会话，只是复制认证配置，通常是你想要的。
		只有下面情况才建议选 `No`：
		- 你想让这个新 agent 用完全不同的模型账号/API Key
		- 你想把它做成隔离环境
		- 你准备后面手动重新配置认证
