## 一、ClawManager 是什么

ClawManager 是一个 **Kubernetes 原生的 AI Agent 实例管理控制平面**，用于企业级部署和管理 OpenClaw（开源 AI Agent 网关）。它为平台团队提供统一的 Web 界面来创建、监控、治理 AI Agent 工作空间，替代传统的命令行运维方式。

**一句话定位**：面向多用户、多实例的 AI Agent 基础设施管控平台。

---

## 二、核心功能

### 2.1 三大控制平面

|                                |                                            |
| ------------------------------ | ------------------------------------------ |
| 控制平面                           | 功能                                         |
| **AI Gateway（AI 网关）**          | 统一模型访问入口、安全模型路由、审计追踪、成本核算、风控规则             |
| **Agent Control Plane（运行时编排）** | Agent 注册与心跳、状态同步、命令下发（启停/配置/健康检查）、期望态管理    |
| **Resource Management（资源管理）**  | Channel/Skill 资源维护、Bundle 资源包组合、安全扫描、注入与快照 |
|                                |                                            |

### 2.2 AI 网关能力

- **模型治理**：支持 OpenAI、Anthropic、DeepSeek、Ollama 等 10+ 模型厂商的统一接入
    
- **审计追踪**：每次模型调用均有完整 Trace 记录（请求/响应/Token/路由）
    
- **成本核算**：按用户、按实例维度统计 Token 用量和费用
    
- **风控规则**：内置 50+ 敏感信息检测规则（个人信息、API Key、内网 IP 等），命中后可阻断或路由到安全模型
    

### 2.3 实例管理

- 通过 Web 页面一键创建 OpenClaw Desktop 实例（自动调度 K8s Pod、PVC、NetworkPolicy）
    
- 支持实例生命周期管理（创建/停止/删除）
    
- 用户配额管理（CPU/内存/存储/GPU 上限）
    
- 实例状态实时监控
    

### 2.4 安全中心（Skill Scanner）

- 对上传的 Skill 进行多维度安全扫描（静态规则、字节码校验、行为分析、LLM 语义分析）
    
- 风险等级分类与扫描覆盖率看板
    
- Quick / Deep 两套扫描策略可配置
    
![[ClawManager 技术评估报告-1779780131334.webp]]
### 2.5 资源管理

- **通道**：支持 Telegram、Discord、Slack、飞书/Lark、钉钉等 13+ 消息平台的接入模板
    
- **技能**：支持 ZIP 归档批量上传，自动解析为独立技能
    
- **资源包**：将通道+技能组合为可复用的 Bundle，一次性注入实例

## 三、优点

### 3.1 架构设计

- **Kubernetes 原生**：与 K8s 深度集成，天然具备弹性伸缩、自动恢复能力
    
- **控制平面分层清晰**：AI 治理、运行时编排、资源管理三层解耦
    
- **多租户隔离**：每个用户独立 Namespace，NetworkPolicy 网络隔离
    

### 3.2 安全与合规

- **数据本地化**：所有 Agent 配置、API Key、会话数据存储在自有集群，不经过第三方
    
- **AI 调用审计**：每次模型调用有完整链路追踪，满足企业合规需求
    
- **敏感信息检测**：内置风控规则引擎，可阻断包含敏感信息的请求
    
- **Skill 安全扫描**：上传的技能包经过静态+行为+语义多重扫描
    

### 3.3 运维友好

- **全 Web 化管理**：无需命令行，非技术人员也能操作
    
- **一键部署**：单个 YAML 清单包含全部组件（MySQL、应用、Scanner）
    
- **MIT 开源协议**：无商业限制，可自由修改和二次开发
    

### 3.4 扩展性

- 模型厂商可自由扩展（OpenAI Compatible 协议）
    
- 支持本地模型（Ollama / LM Studio）
    
- 通道模板可自定义

## 四、缺点与不足

### 4.1 产品成熟度

- **项目较新**（2026 年 3 月起步），589 Stars，文档覆盖面有限
    
- **部分功能标注「即将上线」**：智能体管理、定时任务等尚未完成
    
- **已运行实例不支持热注入资源**，修改通道/技能配置需要删除重建实例
    
- **错误提示不够友好**：如实例名使用中文会报底层 K8s 错误而非用户友好提示
    

### 4.2 平台兼容性

- **仅提供 amd64 镜像**：`skill-scanner` 和 `openclaw` 镜像无 ARM64 版本，Apple Silicon Mac 无法直接运行
    
- **第三方 ARM64 镜像（`ghcr.io/xty00/`）为私有仓库**，无法匿名拉取
    
- 从源码构建需要访问 Docker Hub / GitHub，国内网络受限
    

### 4.3 部署依赖

- **强依赖 Kubernetes**：最低要求一个可用 K8s 集群，对小型团队有一定门槛
    
- **依赖外部 AI API Key**：核心功能（创建实例）必须先配置「安全模型」
    
- **存储依赖**：MySQL + 持久卷，需要可靠的 StorageClass
    

### 4.4 性能与规模

- 当前为**单节点架构**，无高可用部署方案
    
- OpenClaw Desktop 实例是完整 Linux 桌面环境（Xvfb + WebRTC），单实例消耗 2CPU/4GB+
    
- 大规模多实例场景下的性能和调度能力尚未验证

## 五、使用限制

|   |   |
|---|---|
|限制项|说明|
|K8s 版本|需要 Kubernetes 1.26+|
|服务器架构|推荐 x86_64 Linux，ARM64 需自行构建镜像|
|实例名称|仅支持英文/数字/`-`/`_`/`.`，不支持中文|
|安全模型|创建实例前必须配置至少一个 AI 安全模型|
|Skill Scanner LLM|深度扫描需要额外配置 LLM，否则仅支持静态扫描|
|网络要求|飞书等消息平台回调需要公网可达的地址|
|资源注入|不支持对已运行实例热注入，需重建实例|
|多集群|当前版本不支持多集群管理|

## 七、总结

ClawManager 是目前少有的 **开源 AI Agent 基础设施管控平台**，定位清晰，架构合理。其 AI 网关的审计追踪、成本核算和风控规则能力是核心差异化优势，适合需要统一管理 AI Agent 的企业团队。

**主要风险**在于项目成熟度——功能仍在快速迭代中，部分特性未完成，ARM64 支持不完善，缺乏生产级高可用方案。建议在 x86 Linux 测试环境中进一步验证后，再评估生产环境引入。
