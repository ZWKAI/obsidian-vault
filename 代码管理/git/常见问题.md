## git问题汇总
### git pull 代码冲突
**方案一** 暂时贮藏修改（推荐）
	贮藏当前修改
	git stash
	拉取远程更新
	git pull
	恢复贮藏的修改（可选）
	git stash pop
**方案二** 放弃本地对 `.DS_Store` 的修改
	恢复 .DS_Store 到远程版本
	git checkout -- .DS_Store
	然后拉取
	git pull
**方案三** 直接删除该文件后拉取
	删除 .DS_Store
	rm .DS_Store
	拉取更新
	git pull
**长期解决方案**：将 `.DS_Store` 加入 `.gitignore`
	在项目根目录创建或编辑 .gitignore 文件
	echo ".DS_Store" >> .gitignore
	如果仓库中已经存在 .DS_Store，需要从 Git 中移除
	git rm --cached .DS_Store
	提交更改
	git add .gitignore
	git commit -m "chore: ignore .DS_Store files"

### git stash pop 代码冲突
 **方案一**：直接接受远程版本
	删除冲突的 .DS_Store
	rm .DS_Store
	告诉 Git 冲突已解决（使用远程版本）
	git add .DS_Store
	完成合并
	git stash drop

**方案二**：放弃远程版本，保留本地修改
	使用本地贮藏的版本
	git checkout --ours .DS_Store
	标记为已解决
	git add .DS_Store
	删除贮藏
	git stash drop
**方案三**：最简单 - 直接删除并忽略
	删除 .DS_Store
	rm .DS_Store
	放弃所有关于 .DS_Store 的冲突
	git checkout --theirs .DS_Store
	清理贮藏
	git stash drop
