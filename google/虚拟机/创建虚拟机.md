既然你有谷歌赠金，在 GCP（Google Cloud Platform）上直接开一台位于**海外（如香港、台湾、美国）**的服务器是最佳选择。这样服务器可以直连 Google API，不需要配置任何代理，且 OpenClaw 的运行费用（计算费、流量费）会直接从赠金中扣除。

以下是完整的“白嫖”与配置指南：

---

### 第一步：创建虚拟机 (VM Instance)

1. **登录控制台：** 访问 [GCP Console](https://console.cloud.google.com/)。
    
2. **进入计算引擎：** 点击左侧菜单的 **Compute Engine** -> **VM 实例**。
    
3. **创建实例：**
    
    - **名称：** `openclaw-server`。
        
    - **区域 (Region)：** * 追求**低延迟**（如果你在中国）：选 `asia-east1` (台湾) 或 `asia-northeast1` (东京)。
        
        - 追求**最强兼容性/最新模型：** 选 `us-central1` (美国中部)。
            
    - **机器配置：** 选 `E2` 系列。
        
        - _建议：_ `e2-medium` (2 vCPU, 4GB 内存)，OpenClaw 跑起来很流畅。
            
    - **操作系统 (Boot Disk)：** 点击“更改”，选择 `Ubuntu 22.04 LTS`，大小建议 20GB 以上。
        
    - **防火墙 (Firewall)：** **勾选** “允许 HTTP 流量” 和 “允许 HTTPS 流量”。
        

---

### 第二步：配置防火墙规则（关键）

OpenClaw 默认通常占用 `3000` 或 `8080` 端口。GCP 默认关闭这些端口，你需要手动打开：

1. 在搜索框搜索 **“VPC 网络防火墙”** (VPC Network Firewall)。
    
2. 点击 **“创建防火墙规则”**：
    
    - **名称：** `allow-openclaw`。
        
    - **流量方向：** 入站。
        
    - **目标：** 网络中的所有实例。
        
    - **来源 IPv4 范围：** `0.0.0.0/0`（允许所有人访问，如果为了安全可以填你自己的固定 IP）。
        
    - **协议和端口：** 勾选 `指定的协议和端口` -> `tcp` -> 填入 `3000` (或其他 OpenClaw 使用的端口)。
        

---

### 第三步：一键部署 OpenClaw

1. 在 VM 实例页面，点击该机器右侧的 **SSH** 按钮，弹出一个黑色的终端窗口。
    
2. **安装 Docker（OpenClaw 的基础）：**
    
    Bash
    
    ```
    curl -fsSL https://get.docker.com | sudo sh
    sudo usermod -aG docker $USER
    # 注销并重新连接 SSH，或者直接用 sudo 运行后续命令
    ```
    
3. **部署 OpenClaw：**
    
    通常使用 Docker 一键启动（请参考你所使用的 OpenClaw 具体版本的命令）：
    
    Bash
    
    ```
    docker run -d --name openclaw \
      -p 3000:3000 \
      --restart always \
      -e NODE_ENV=production \
      openclaw/openclaw:latest
    ```
    
    _(注：如果是分发版，请替换对应的镜像名和环境变量)_
    

---

### 第四步：配置 Gemini API (利用赠金)

因为这台机器在 GCP 内部：

1. **Base URL：** 直接填官方地址 `https://generativelanguage.googleapis.com`。
    
2. **API Proxy：** **留空**（不需要填那个 127.0.0.1 了）。
    
3. **访问：** 在浏览器输入 `http://你的服务器外部IP:3000` 即可登录 OpenClaw。
    

---

### 💡 进阶：如何确保是“白嫖”？

- **查看扣费：** 每天去 **“结算 (Billing)”** 页面。你会看到产生了费用，但下面会有一行 **“Credit”** 将其抵消，最终账单为 $0。
    
- **静态 IP：** GCP 的临时外部 IP 重启后会变。建议在 **VPC 网络 -> IP 地址** 中，将该 IP 设置为“静态”，这样你的 OpenClaw 地址就不会变了。
    
- **预算提醒：** 在结算页面设置一个 $10 的预警，万一流量超标或赠金用完，你会收到邮件，防止信用卡被扣款。
    

**现在你的服务器已经在海外了，那个 `1006` 报错和 `127.0.0.1` 的代理问题都会彻底消失。如果安装命令卡住了，请告诉我！**
